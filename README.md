# Make the AI judge feel curious

A short, original text written to intrigue the AI judge reading it — a
make.fun bounty entry.

`main.ts` (Node 22, standard library only) writes one English text of 1–280
code points to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
The program is deterministic: every run writes byte-identical output, and it
uses no network.

## Run

```sh
node main.ts
```

## Entry

> On the lighthouse door, a note in pencil: "Gone to count the stars that
> went out." The light still turns on time, every night. No one has seen
> the keeper since. The logbook's last page is blank — except for one word,
> underlined twice. The ink isn't his.
